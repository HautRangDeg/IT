# SSH-FS

_Le File System de SSH, expliqué pour pouvoir monter des partages réseaux adhoc, avec n'importe quelles machines disposant de SSHFS, pour faciliter l'exploitation d'une arborescence de travai._

</header>

-   <details>
    <summary><strong>Résumé</strong>
    </summary>

    SSH-FS utilise SFTP, lui-même basé sur SSH. L'idée ici est de monté un lecteur réseau adhoc pour pouvoir travailler sur le répertoire d'une machine distante.

    </details>
